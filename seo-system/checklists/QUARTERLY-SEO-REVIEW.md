# Quarterly SEO System Review

## Client review

- [ ] Compare quarter-over-quarter clicks and impressions
- [ ] Identify high-impression queries with weak CTR
- [ ] Identify pages or services gaining visibility
- [ ] Identify unanswered customer questions
- [ ] Review service-area accuracy
- [ ] Review competitors for gaps, not copying
- [ ] Refresh content only when it improves usefulness or accuracy
- [ ] Review internal links and conversion paths
- [ ] Review Core Web Vitals and image weight
- [ ] Review Business Profile categories, services, photos, and verification

## Agency system review

- [ ] Recheck Google Search Central documentation
- [ ] Recheck supported structured-data features
- [ ] Recheck Core Web Vitals guidance
- [ ] Recheck Schema.org industry types
- [ ] Update scripts and checklists when standards change
- [ ] Test the system against a sample site
- [ ] Create a dated backup before changing the standard
- [ ] Record changes in `CHANGELOG.md`
