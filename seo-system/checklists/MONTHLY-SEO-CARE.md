# Monthly SEO Care Checklist

- [ ] Run `monthly_seo_check.py`
- [ ] Confirm homepage, robots.txt, and sitemap return 200
- [ ] Confirm HTTPS, canonical, indexability, H1, social image, and JSON-LD
- [ ] Review Search Console last 28 days vs previous 28 days
- [ ] Review clicks, impressions, CTR, position, top queries, and top pages
- [ ] Review indexing and Core Web Vitals
- [ ] Review Google Business Profile status and website link
- [ ] Confirm business name, phone, hours, services, prices, and service area
- [ ] Test the primary lead action
- [ ] Check broken links and missing images
- [ ] Check outdated promotions or seasonal content
- [ ] Record changes completed
- [ ] Record recommendations needing approval
- [ ] Send the client a plain-language care summary

## Client summary format

1. What we checked
2. What is working
3. What changed
4. What needs the client’s attention
5. What we will watch next month

Never report a ranking guarantee or imply that ordinary fluctuations are a crisis.
