# Prelaunch SEO Checklist

## Business truth

- [ ] Business name matches the client approval
- [ ] Phone and email are correct
- [ ] Storefront address or service area is correct
- [ ] Hours are correct
- [ ] Services, prices, payments, and policies are correct
- [ ] Claims are supported
- [ ] Image rights are confirmed
- [ ] Google Business Profile is client-owned
- [ ] No previous-client content remains

## Page content

- [ ] One primary search intent
- [ ] One H1
- [ ] Logical H2/H3 structure
- [ ] Primary service and city appear naturally
- [ ] Services are explained in customer language
- [ ] Service area is visible
- [ ] FAQs are visible and truthful
- [ ] Primary call to action is clear

## Technical

- [ ] HTTPS
- [ ] Preferred host redirects consistently
- [ ] Unique title and meta description
- [ ] Self-referencing canonical
- [ ] Production page is indexable
- [ ] Open Graph title, description, URL, image, and image alt
- [ ] Twitter large-image card
- [ ] JSON-LD parses
- [ ] Correct LocalBusiness subtype
- [ ] No unverified rating schema
- [ ] robots.txt loads and does not block production
- [ ] sitemap.xml loads and uses canonical HTTPS URLs
- [ ] Manifest and icons load
- [ ] No broken internal links or assets
- [ ] No console-blocking errors

## Images and experience

- [ ] Images are compressed
- [ ] Modern image formats used
- [ ] Alt text is appropriate
- [ ] Decorative images use empty alt
- [ ] Width and height are set when practical
- [ ] Hero image is not lazy-loaded
- [ ] Below-fold images are lazy-loaded
- [ ] Mobile layout has no overlap or horizontal scroll
- [ ] Keyboard navigation works
- [ ] Form labels and error messages are understandable

## Conversion

- [ ] Contact/quote form delivers to the correct client
- [ ] Thank-you message works
- [ ] Phone and text links work
- [ ] Booking link works
- [ ] Google Maps/directions link works when used
- [ ] Spam protection works

## Validation and launch

- [ ] Automated audit score is 90+
- [ ] No critical findings
- [ ] Rich Results Test reviewed
- [ ] PageSpeed Insights reviewed
- [ ] Client approved final website
- [ ] Backup created
- [ ] Production deployed
- [ ] Search Console verified
- [ ] Sitemap submitted
- [ ] Homepage inspected/requested for indexing
- [ ] Google Business Profile website URL aligned
- [ ] Baseline recorded
